## Project Overview

This project is a Shipment Tracking & Analysis System in Excel.
It allows users to:

Track shipments with status, boxes, and amounts.

Calculate KPIs and revenue metrics.

Visualize data with interactive PivotTables and charts.

Automate reporting using VBA macros.

## Project Objectives

Provide clear visibility of shipment status and trends.

Enable quick identification of late or returned shipments.

Create a dashboard for management decision-making.

Automate repetitive reporting tasks.

## Technologies Used

Microsoft Excel (Tables, Formulas, PivotTables, Charts)

Excel VBA for automation
